## Decisions

- **Verification:** changes go in by Houston push or API, not by full catalogue exports. Stefan won't upload 16 MB exports any more.
- **SKUs:** use them exactly as stored. Never pad, trim or retype.
  - 7-digit padding was wrong for 136 of 516 live products: 5- and 6-digit SKUs, 8-digit SKUs with a leading zero, trailing spaces, one 17-digit SKU.
- **Copy:** Claude drafts Romanian copy, Stefan approves it.
- **Write-back route:** the store API (cleared by Blugento in writing, Oct 2026). Dataflow file import also works and is kept as a fallback.
- **Database:** SQLite, because Houston writes while the MCP connection reads. Future sources get their own tables, with every row dated.
- **MCP:** reads Houston's local copy only. No live store reads and no API key in the Claude config.
- **Content audit:** no fixed character limits for titles or meta descriptions. Google shortens them to fit the screen.
